# Example: B2B churn discovery

End-to-end example using the `churn-root-cause-analysis` recipe.

**Scenario**: Mid-market accounts churning at month 6. Multi-channel signal available.

## Skills used

`signal-archaeologist` → `voc-conductor` → `interview-decoder` → `insight-distiller` → `problem-prism`

## Synthetic input

Synthetic ticket archive, NPS verbatims, sales call notes, and 5 exit interviews.

## Expected artefacts

A churn root-cause memo with confidence-rated insights, contradictions, and a recommended reframe.
