# Example: SaaS onboarding research

A worked end-to-end example using the `quick-discovery-sprint` recipe.

**Scenario**: A vertical SaaS company suspects activation friction in the first 24 hours. PM has 4 onboarding interviews and one day to act.

## Skills used

1. `interview-decoder` — code the 4 transcripts
2. `jtbd-extractor` — extract jobs from coded data
3. `opportunity-triangulator` — size the activation opportunity

## Synthetic input

`transcript-01.md` through `transcript-04.md` — synthetic interview transcripts (do **not** use real customer data; replace with your own anonymized files).
